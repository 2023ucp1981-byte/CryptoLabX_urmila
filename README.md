# CryptoLabX

## Week 1 - Project Foundation

CryptoLabX is a modular cryptanalysis toolkit being developed as part of the
cryptography coursework. The project will gradually be extended with
classical cryptography, cryptanalysis attacks, mathematical utilities,
modern cryptography and data analysis modules.

Week 1 focuses only on establishing the software project foundation.
No cryptographic algorithms are implemented in this version.

---

## Learning Outcomes

The Week 1 project demonstrates:

- Professional software project organization
- Git and GitHub version control
- Modular project structure
- Command-line interface development
- Basic file handling
- Text file analysis
- Logging
- Project documentation
