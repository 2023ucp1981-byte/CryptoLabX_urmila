# Hospital Management System

## Lab Assignment 3

This project implements a small console-based Hospital
Management System using Java.

## Core Functionalities

1. Patient Registration
2. Appointment Management
3. Prescription Management
4. Billing
5. Medical Records

## Vulnerabilities Demonstrated

1. SQL Injection
2. Broken Access Control
3. File Upload Vulnerability

## Technology

Programming Language: Java

## Project Structure

secure_application/
├── src/
├── reports/
├── screenshots/
├── sast/
├── outputs/
└── testcases/

## Testing

Test cases are documented in the testcases directory.

## SAST Analysis

Static Application Security Testing is performed on the
source code. SAST results are stored in the sast directory.

## Conclusion

The project demonstrates basic hospital management
functionality and selected application security
vulnerabilities for educational purposes.
